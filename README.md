# Pangasinan Heritage & Tourism Website

## Project Title
Pangasinan Heritage & Tourism Website

## Student Name
Delacruz, Gerald P.

## Selected Framework
Next.js with React and TypeScript

## Live Website
[Open the Pangasinan Heritage website](https://geralddelacruz082504-create.github.io/pangasinanweb-heritage-tourism/)

## Project Description
A modern static tourism website that showcases the heritage, culture, natural beauty, and destinations of Pangasinan.

## Features
- Responsive and mobile-first design
- Static Site Generation (SSG)
- Reusable Atomic Design components
- Tourism destinations showcase
- Heritage and cultural information
- GitHub Pages deployment

## Getting Started

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

Edit `app/page.tsx` to update the page.
